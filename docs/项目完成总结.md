## 🚀 如何使用

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
创建 `.env` 文件，配置 API 密钥

### 3. 运行测试
```bash
python test_e2e.py
```

### 4. 启动服务
```bash
python main.py
```

### 5. 访问 API
- API 文档: http://localhost:8000/docs
- 健康检查: http://localhost:8000/health

## 🎯 核心流程

1. **热点追踪** → 从多个数据源获取热点数据
2. **剧本生成** → 基于热点使用 LLM 生成视频剧本
3. **视频生成** → 将剧本转换为成品视频
4. **任务调度** → 定时自动执行完整工作流

## 📝 设计特点

1. **模块化设计**: 各模块职责清晰，独立可测试
2. **策略模式**: 数据源、LLM、视频生成策略可配置切换
3. **解耦设计**: 模块间通过接口通信，便于扩展
4. **配置驱动**: 支持通过配置文件管理策略和参数

## ⚠️ 注意事项

1. **API 密钥**: 需要配置有效的 API 密钥才能使用 AI 功能
2. **视频生成**: 当前使用模拟实现，实际部署需要配置真实的视频生成 API
3. **数据存储**: MVP 版本使用文件存储，生产环境建议使用 PostgreSQL
4. **安全**: 当前版本未实现用户权限和加密，生产环境需要补充
