# 环境使用说明

## 环境对比结果

### ✅ 本地环境 vs 虚拟环境

| 项目 | 本地环境 | 虚拟环境 | 结论 |
|------|---------|---------|------|
| Python 版本 | 3.9.6 | 3.9.6 | ✅ 一致 |
| PyTorch | 2.8.0 | 2.8.0 | ✅ 一致 |

### 结论

**可以直接使用本地环境运行代码！**

两个环境的包版本完全一致，功能相同。

## 使用方式

### 方式1：本地环境（推荐，更简单）

```bash
# 直接运行，无需激活虚拟环境
python3 test_cogvideo.py 1
python3 test_e2e.py
```

### 方式2：虚拟环境（隔离性好）

```bash
# 激活虚拟环境
source venv/bin/activate

# 运行测试
python test_cogvideo.py 1
python test_e2e.py
```

## 模型文件损坏修复

如果遇到模型文件损坏错误（如 `invalid JSON in header`），运行：

```bash
python3 fix_cogvideo_model.py
```

这会清理损坏的模型文件，下次运行时会自动重新下载。

## 常见问题

### Q: 为什么两个环境的包版本一样？

A: 可能是因为虚拟环境创建时使用了 `--system-site-packages` 选项，或者本地环境已经安装了这些包。

### Q: 应该用哪个环境？

A: 
- **本地环境**：更简单，无需激活，适合快速测试
- **虚拟环境**：隔离性好，不会污染系统，适合正式开发

### Q: 如何确保环境一致？

A: 使用 `requirements.txt` 安装依赖：
```bash
pip install -r requirements.txt
```
