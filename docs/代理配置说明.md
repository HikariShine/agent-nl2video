# Hugging Face 代理配置说明

## 为什么需要代理？

在国内访问 Hugging Face 下载模型时，可能会遇到：
- 网络连接超时
- 下载速度慢
- 429 限流错误

使用代理可以解决这些问题。

## 配置方法

### 方法1：环境变量（推荐）

在终端中设置环境变量：

```bash
# HTTP 代理
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890

# 或者带认证的代理
export HTTP_PROXY=http://user:pass@proxy_host:port
export HTTPS_PROXY=http://user:pass@proxy_host:port
```

然后运行测试：
```bash
python3 test_cogvideo.py 1
```

### 方法2：.env 文件配置

在 `.env` 文件中添加：

```bash
# HTTP 代理
HTTP_PROXY=http://127.0.0.1:7890

# HTTPS 代理
HTTPS_PROXY=http://127.0.0.1:7890
```

### 方法3：代码中配置

在 `cogvideo_strategy.py` 的配置中传递：

```python
config = {
    "storage_path": "./storage/videos",
    "http_proxy": "http://127.0.0.1:7890",
    "https_proxy": "http://127.0.0.1:7890",
}
```

## 常见代理工具

### Clash
```bash
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
```

### V2Ray
```bash
export HTTP_PROXY=http://127.0.0.1:10809
export HTTPS_PROXY=http://127.0.0.1:10809
```

### Shadowsocks
```bash
# 需要配合 privoxy 或 proxychains
export HTTP_PROXY=http://127.0.0.1:8118
export HTTPS_PROXY=http://127.0.0.1:8118
```

## 验证代理是否生效

运行测试时，如果看到以下输出，说明代理已生效：

```
使用代理: {'http': 'http://127.0.0.1:7890', 'https': 'http://127.0.0.1:7890'}
```

## 注意事项

1. **代理格式**：必须是完整的 URL，包括协议（http:// 或 https://）
2. **端口号**：确保代理工具的端口号正确
3. **代理状态**：确保代理工具正在运行
4. **测试连接**：可以先测试代理是否能访问 huggingface.co

## 测试代理连接

```bash
# 测试 HTTP 代理
curl -x http://127.0.0.1:7890 https://huggingface.co

# 如果返回 HTML 内容，说明代理正常
```

## 故障排查

### 问题1：代理未生效
- 检查环境变量是否正确设置：`echo $HTTP_PROXY`
- 检查代理工具是否运行
- 检查端口号是否正确

### 问题2：连接超时
- 尝试更换代理服务器
- 检查防火墙设置
- 使用更稳定的代理工具

### 问题3：认证失败
- 如果代理需要认证，使用格式：`http://user:pass@host:port`
- 检查用户名和密码是否正确

## 不使用代理的替代方案

如果无法使用代理，可以考虑：

1. **使用 Hugging Face 镜像站**（如果可用）
2. **手动下载模型**：从 Hugging Face 网站手动下载模型文件
3. **使用国内模型托管服务**（如果有）
