# 本地视频生成方案

## 概述

由于没有 OpenAI 账号，项目提供了本地视频生成策略作为降级方案。该方案使用 MoviePy 在本地生成视频，不需要任何 API 密钥。

## 当前实现

### LocalVideoStrategy（本地视频生成策略）

**特点**：
- ✅ 完全本地运行，不需要 API 密钥
- ✅ 不需要 GPU，CPU 即可运行
- ✅ 支持字幕、背景音乐
- ✅ 基于 MoviePy，稳定可靠

**生成内容**：
- 彩色背景视频（每个场景不同颜色）
- 字幕叠加（白色文字，黑色描边）
- 背景音乐（简单的音调）

## 使用方法

### 1. 配置使用本地策略

在配置文件中设置：

```python
VIDEO_CONFIG = {
    "strategy": "local",  # 使用本地策略
    "strategy_config": {
        "storage_path": "./storage/videos",
    },
    "post_process": {
        "add_subtitles": True,
        "add_music": True,
    },
}
```

### 2. 运行测试

```bash
python test_e2e.py
```

## 其他本地视频生成方案（可选）

如果需要更高级的本地视频生成，可以考虑以下方案：

### 方案1: AnimateDiff（图片转视频）

**优点**：
- 可以从静态图片生成视频
- 质量较好
- 支持多种风格

**缺点**：
- 需要 GPU
- 模型较大（约 2-3GB）
- 生成速度较慢

**安装**：
```bash
pip install diffusers transformers torch
```

**使用示例**：
```python
from diffusers import AnimateDiffPipeline, MotionAdapter
from diffusers.utils import export_to_gif

pipe = AnimateDiffPipeline.from_pretrained(
    "guoyww/animatediff-motion-adapter-v1-5-2",
    torch_dtype=torch.float16
)
pipe = pipe.to("cuda")

# 从图片生成视频
output = pipe(
    prompt="a beautiful landscape",
    num_inference_steps=25,
    guidance_scale=7.5,
)
export_to_gif(output.frames[0], "output.gif")
```

### 方案2: Stable Video Diffusion

**优点**：
- 专门用于视频生成
- 质量较高
- 支持多种分辨率

**缺点**：
- 需要 GPU
- 模型较大（约 4GB）
- 需要较多显存

**安装**：
```bash
pip install diffusers transformers accelerate
```

### 方案3: 图片序列 + FFmpeg

**优点**：
- 最简单
- 不需要深度学习模型
- 速度快

**缺点**：
- 需要预先准备图片
- 视频内容有限

**实现思路**：
1. 使用文本生成图片（如 Stable Diffusion）
2. 将图片序列转换为视频（FFmpeg）

```python
import subprocess

# 使用FFmpeg将图片序列转为视频
subprocess.run([
    'ffmpeg', '-framerate', '24',
    '-i', 'frame_%04d.png',
    '-c:v', 'libx264',
    '-pix_fmt', 'yuv420p',
    'output.mp4'
])
```

## 推荐方案

**当前阶段（MVP）**：
- ✅ 使用 `LocalVideoStrategy`（MoviePy）
- 简单、快速、稳定
- 适合测试和演示

**后续优化**：
- 如果需要更真实的视频内容，可以考虑集成 Stable Diffusion 生成图片，然后转为视频
- 或者等待 Sora API 公开后使用

## 配置示例

### 使用本地策略（默认）

```python
VIDEO_CONFIG = {
    "strategy": "local",
    "strategy_config": {
        "storage_path": "./storage/videos",
    },
}
```

### 使用 Sora（如果有 API 密钥）

```python
VIDEO_CONFIG = {
    "strategy": "sora",
    "strategy_config": {
        "api_key": "your_openai_api_key",
        "storage_path": "./storage/videos",
    },
}
```

## 注意事项

1. **MoviePy 依赖**：确保已安装 MoviePy
   ```bash
   pip install moviepy
   ```

2. **FFmpeg**：MoviePy 需要 FFmpeg，确保系统已安装
   - macOS: `brew install ffmpeg`
   - Linux: `apt-get install ffmpeg`
   - Windows: 下载 FFmpeg 并添加到 PATH

3. **性能**：本地生成速度取决于 CPU 性能，通常 60 秒视频需要 10-30 秒生成时间

4. **存储**：生成的视频文件会保存在 `storage/videos/` 目录
